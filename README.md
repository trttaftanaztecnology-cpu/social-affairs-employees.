# موظفو مبنى مديرية الشؤون الاجتماعية

نسخة Android قابلة للبناء على GitHub Actions.

الواجهة عربية RTL وتحتوي على:
- شاشة البداية
- تسجيل اسم الموظف
- قائمة الموظفين
- الأقسام
- المحادثات
- الإعدادات
- معلومات الشبكة

هذه النسخة هي واجهة وتجربة أولية. الاتصال الحقيقي بين عدة هواتف يحتاج طبقة شبكة محلية/خادم أو اتصال نظير إلى نظير.
